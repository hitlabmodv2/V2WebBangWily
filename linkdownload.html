📚 Tutorial Lengkap Setup Bot di Pterodactyl Panel

🎥 Video Tutorial Setup Bot Pterodactyl
▼

🎯 Penjelasan Lengkap: Video ini menunjukkan cara setup bot WhatsApp di panel Pterodactyl mulai dari upload script, instalasi dependencies, hingga menjalankan bot dengan sukses.

🔧 Langkah-Langkah Setup Bot
▼
1

Persiapan Awal

  • ✅ Panel Pterodactyl dengan akses server
  • ✅ Script bot auto reaction story (download dari atas)
  • ✅ File manager atau akses SFTP
  • ✅ Koneksi internet yang stabil
2

Upload Script ke Server

  1. Buka panel Pterodactyl Anda
  2. Masuk ke server bot WhatsApp
  3. Buka menu File Manager
  4. Upload file script bot yang sudah didownload
  5. Extract file zip jika diperlukan
📁 Struktur folder yang benar:
/home/container/
├── package.json
├── index.js
├── config.js
└── node_modules/
3

Instalasi Dependencies

Jalankan perintah di console Pterodactyl:

npm install

Atau install manual:

npm install @whiskeysockets/baileys qrcode-terminal fs path
4

Konfigurasi Bot

Edit file config.js atau index.js:

const config = {
  autoReaction: true,
  selfMode: false,
  prefix: '.',
  ownerNumber: '6289688206739'
}
5

Menjalankan Bot

node index.js

🔧 Troubleshooting & Tips
▼

❌ Error "Module not found"

Solusi: Jalankan npm install terlebih dahulu

❌ QR Code tidak muncul

Solusi: Pastikan terminal/console dapat menampilkan QR code

❌ Bot tidak merespon

Solusi: Cek koneksi internet dan restart bot

❌ Session terputus

Solusi: Hapus folder session dan scan QR code ulang

💡 Tips & Tricks

🔄 Gunakan PM2 untuk auto restart bot
📊 Monitor resource usage di panel
💾 Backup session secara berkala
🔐 Jangan share session folder dengan orang lain
⚡ Gunakan server dengan RAM minimal 512MB
